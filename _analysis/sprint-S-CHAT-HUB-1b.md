## КЛЮЧЕВЫЕ РЕШЕНИЯ (принять как есть)

1. **Пустые проектные каналы по умолчанию скрыты.** Показываем: общий канал (всегда,
   закреплён сверху) + проектные, где есть хоть одно сообщение, по свежести. Остальные —
   под раскрывающейся строкой «Показать все проекты (N)». Причина: каналы заводятся
   автоматически на каждый проект, и список из 19 строк, где 17 пустых, — это не навигация,
   а шум. Состояние «раскрыто» держим в локальном стейте, не в URL.
2. **Активный канал — в URL:** `/chat?c=<conversationId>`. Конвенция проекта (URL state для
   фильтров и активных вкладок), плюс ссылка на канал становится отправляемой. Без `c` —
   пустое состояние «Выберите канал», НЕ автовыбор первого: автовыбор при live-обновлении
   списка перекидывал бы пользователя между каналами.
3. **Бейдж = число каналов с непрочитанным**, не число сообщений. `conversation_reads`
   хранит `last_read_at`, а не счётчик; считать сообщения после отметки — это ещё один
   запрос на канал. Точка вместо числа честнее отражает то, что мы реально знаем.
4. **Вкладка «Чат» на карточке сделки остаётся** и открывает тот же канал. Один источник,
   две точки входа — это уже сделано в 1a, ничего не трогаем.
5. **`MessageThread` не меняем по поведению.** Он уже принимает `conversationId` /
   `title` / `emptyText`. Если для страницы нужна другая высота — прокидываем пропом
   (`className` или `heightClass`), а не форкаем компонент.

## ЗАДАЧА 3 — `ChannelList`

`src/components/chat/ChannelList.tsx`. Пропы: `activeId: string | null`,
`onSelect(id: string): void`.

Данные — `useConversations()`. Раскладка:

1. **Общий чат** — всегда первой строкой, визуально отделён (разделитель под ним).
2. **Проекты с сообщениями** — `lastMessageAt !== null`, порядок из хука.
3. **`<button>` «Показать все проекты (N)»** — N = число пустых; по клику раскрывает
   остальные. Если пустых нет — кнопки нет. Если непустых нет вообще — сразу показываем
   всё без кнопки (иначе на старте пользователь видит один общий канал и не понимает, где
   проекты).

Строка канала: название (truncate), справа — время последнего сообщения (МСК, сегодня →
`HH:MM`, иначе `DD.MM`; форматтеры МСК уже есть в `MessageThread` — вынеси в
`src/lib/utils/date-helpers.ts`, если тянешь их во второй файл, не дублируй), точка
непрочитанного. Активная строка — по существующей идиоме навигации (`data-active`), цвета
только через CSS-переменные.

Доступность: список — `<nav>` с `aria-label="Каналы"`, строки — `<button>` с
`aria-current="true"` у активной.

- `?c=` указывает на канал, которого нет или не виден по RLS: тред не грузится → показать
  «Канал недоступен» и снять параметр одним `router.replace`.

  ключ запроса включает `conversationId`, проверь, что не остаётся `keepPreviousData`.

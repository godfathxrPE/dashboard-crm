### Задачи из чата

`/задача звонок Ориент 3 августа в 15:00` в канале сделки → сообщение уходит в канал →
карточка подтверждения → задача с дедлайном 15:00 МСК, привязкой к сделке и
`source_message_id`. Второй вход — иконка на любом сообщении.

- **Привязка по приоритету:** явный выбор → чип-ссылка в сообщении → **канал проекта** →
  подсказка из текста. Канал знает свой `project_id` — это главный бесплатный контекст.
- **Поиск сущностей по названию** (`use-entity-search`) с экранированием `%`/`_`.
- **Идемпотентность в БД:** partial unique на `source_message_id`. Проверено смоком:
  второй пользователь не видит чужую задачу (RLS), но INSERT всё равно ловит 23505.
- **Парсер дат** — свой, без библиотек, всё в МСК, `now` параметром, 40+ тестов.
- `sourceMessageId` сужен до `string` (не `string | null`) — инвариант держит компилятор.

## 3. Грабли сессии

1. **Я вписал версию 098 из головы** (`20260802181500` вместо `20260802201942`) — ровно
   та грабля, которую сам занёс в прошлый handoff и требовал от CC. Поймал CC при
   разведке. **Версия берётся запросом к `schema_migrations`, всегда.**
2. **Сообщение коммита опережает диф — третий раз.** `a8ec7f5`, `31965bb` заявляли снятие
   стабов, которого не было. Решение принято: **снятие стабов делает гейт**, пользователю
   остаётся `git add` + коммит. Сработало.
3. **Мост и флаги git.** `git --no-optional-locks checkout <branch> --no-optional-locks` —
   хвостовой флаг уходит мусором, содержимое ветки утекает в рабочее дерево, остаётся
   стейл `.git/index.lock` (мост не умеет unlink). **Флаги git — только перед подкомандой.**
4. **Спринт может противоречить сам себе** (1b: задача 3 против EDGE CASES) и
   **недоспецифицировать инвариант** (слэш-путь без `source_message_id` → два дубля в
   проде). Оба раза правил я, не CC.
5. **`\b` в JS ломается на кириллице** — опирается на ASCII-`\w`. Везде `(?![\wа-яё])`.

## Инварианты линейки

1. **Три класса данных, не смешивать.** `okved` — факт реестра (только lookup).
   `industry` — рабочая классификация человека. Результат AI — заметка с источниками.
2. **AI предлагает, человек применяет.** Сайт подставляется кнопкой, молча ничего не пишется.
3. **Каждое утверждение брифа — со ссылкой.** Нет источника — нет утверждения.
4. **Справочники — снапшоты с датой.** ЧЗ от 2026-08, в UI подпись. Из памяти не дополнять.
5. **Вероятностное средство не даёт гарантии.** Промпт снижает частоту, гарантию даёт код
   (урок 1b→1c: `<cite>` лечится `stripCiteTags`, а не просьбой не писать теги).

## Установленные факты (не переоткрывать)

- Причина ретраев брифа — `<cite index="7-5">…</cite>`, механизм цитирования web search
  API. Не грязь со страниц; промпт снижает частоту, но не устраняет.
- `SHAPE_MARKERS` (маркер `</`) работает правильно — он и вывел на причину. Не сужать.
- Ретрай с `priorMessages` требует `tool_result` на каждый `tool_use` прошлой попытки,
  иначе API даёт 400 (`retryTurn` в `index.ts`).
- `chz_signals` пуст у всех прогонов — **корректно**: модель пишет в `summary`, что прямых
  упоминаний ЧЗ нет, но по товарной группе компания попадает. Промпт не править.
- DaData тариф «Подсказки» контакты (телефоны/почты) **не отдаёт**.
- `web_search_20260209` требует модель ≥ Sonnet 4.6; в проде `web_search_20250305`, потому
  что модель подменяется env-переменной без редеплоя.
- Бриф ловит то, чего не знает реестр: у «Вологодского МК» нашёл реорганизацию при
  `inn_status = ACTIVE`.

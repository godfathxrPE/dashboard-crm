- Обновить устаревший комментарий `ProjectChat.tsx:96-98` («цвета зафиксированы аудитом — не менять») — он теперь неверен, переписать под новый аудит разделения пузырей.

### Часть B — эмодзи-пикер в composer
- Кнопка-триггер (smile-иконка lucide) слева от textarea или в её углу; клик → поповер с сеткой эмодзи.
- **Вставка в позицию курсора** в `draft` (трекать `selectionStart`/`selectionEnd` textarea), НЕ просто append в конец. После вставки — вернуть фокус в textarea, курсор после эмодзи.
- **Без тяжёлых зависимостей** (конвенция стека). Лин Cowork: **hand-rolled курированная сетка** (8–10 категорий, частые эмодзи; данные — статический массив в модуле) — ноль runtime-deps, полностью темизуется под `--`-токены. Если Grok/CC настаивают на либе — только self-contained, без внешней сети, темизуемая (напр. emoji-picker-react), пометить как решение.
- Поповер: закрытие по Esc / клику вне / выбору; `role`, клавнавигация (стрелки/Enter), focus-trap не обязателен но фокус-management да.
- Эмодзи — обычный текст в `body` (уже `whitespace-pre-wrap`, React экранирует — XSS-контур цел). Ничего в БД/RLS не меняется.
- Edge cases: пустой draft + эмодзи; maxLength=4000 (эмодзи — многобайтные, счётчик по `.length` уже есть); мобайл/узкий поповер не должен вылезать за виджет.

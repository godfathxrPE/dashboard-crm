Что здесь сравнивается

  • Сейчас — живая карточка. 2a / 2b — варианты Claude Design (правый рейл 400 / левый рейл 360). Синтез — рекомендация: их сильные решения + ограничитель ширины, которого нет ни в одном из трёх.
  • Красный пунктир — сгиб на 1080p (900 CSS px рабочей области). Норма проекта — ≤400px вертикали до основного содержимого (crm-ui-designer §5); в строке замеров эта цифра считается для текущего варианта.
  • Переключай вьюпорт до 2560: у «Сейчас», 2a и 2b полотно тянется линейно — ни один не ставит max-width. У «Синтеза» карточка упирается в 90rem.
  • Наполнение → пусто показывает, во что превращается экран на новой сделке; типично — на живой, с длинным юрлицом и обрезкой.
  • Токены сгенерированы из globals.css скриптом build-mockup.py, список тем — из theme-store.ts. Дефолтная тема проекта — t-aura, рабочая у владельца — t-minimal.

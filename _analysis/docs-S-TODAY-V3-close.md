## ЗАДАЧА 3: `crm-architect/references/learnings.md`

По одной строке-правилу в подходящий раздел; формулировка — в стиле раздела:

- **«Тесты и смоки».** Смок обрезки текста перечисляет все текстовые строки блока, а не две главные: `line-clamp` на третьей строке проходит мимо.
- **«Тесты и смоки».** Ширина 1280 для экрана на контейнерных запросах проверяется сужением контейнера до ширины контента (у «Сегодня» — 994 px): окно под отладчиком расширения не сужается.
- **«React / Next.js».** Глобальный обработчик клавиш на `window` выключается, пока открыта любая форма на месте, через `isActive`: `isInputFocused` не видит кнопок формы, а `preventDefault` на `Enter` отменяет их нажатие.
- **«Домен: факты, дающие ноль строк без ошибки».** Новый шаг сделки поверх старого одним `UPDATE` оставляет в аудите `старая дата → новая`, и `countStepMoves` считает это переносом старого шага. Шаг сначала снимается, потом назначается.
- **«Sprint Prompt Writing».** Правило, взятое из макета, в спринте помечается «из макета, владелец отдельно не подтверждал» и сверяется с текстом, который экран сам печатает об этой группе.
- **«Sprint Prompt Writing».** Спринт-файл содержит строку для STATUS; эпик из трёх спринтов без неё даёт красный `status-check` после каждого мержа.
- **«Процесс DB-спринтов» или «Однострочники процесса».** Из Cowork-VM `git status` оставляет `.git/index.lock`, который VM не может удалить; читать репозиторий только через `git --no-optional-locks`.

## Почему лента, а не сетка — чтобы решение не откатили

Данные org на 09.08: 14 звонков, **1 встреча**, задачи с временем — единицы.
Вертикальная сетка 07:00–22:00 на такой плотности — 90% пустых пикселей и скролл.
Дорожки показывают неделю целиком без скролла, свободные окна видны буквально как
пустые места, а паттерн «время по горизонтали» пользователю уже знаком по Ганту задач.

Цена решения (проговорено при выборе): drag-перенос со снапом 15 минут в v1 не
переезжает. Клик по чипу открывает существующие модалки — редактирование времени там.
Горизонтальный drag — отдельный спринт S-CAL-LANES-2, если попросят руки.

## ЗАДАЧА 1: домен — свободное окно дня

`src/lib/domain/day-windows.ts` — чистая функция, без React:

```ts
export interface TimedInterval { startMin: number; endMin: number }
/** Наибольший свободный промежуток рабочего дня между событиями.
    Рабочая рамка по умолчанию 9:00–18:00 — окно «07–09» никому не нужно. */
export function largestFreeWindow(
  items: TimedInterval[],
  workStart = 9 * 60,
  workEnd = 18 * 60,
): { startMin: number; endMin: number } | null
```

Правила: события сортируются, пересечения сливаются, окно < 45 минут не считается
окном (`null`); события целиком вне рабочей рамки её не сужают. Форматирование
(`«окно 12:20 – 14:20»`, `«весь день свободен»`, `«после 15»` когда окно упирается
в workEnd) — отдельной функцией `formatFreeWindow` там же.

**Тесты обязательны** (`day-windows.test.ts`): пустой день, один интервал в середине,
слившиеся пересечения, окно короче 45 минут, событие за рамкой, окно в конце дня.

## ЗАДАЧА 2: упаковка дорожки

Туда же или в `grid-core.tsx`: `packLane(items) → row: 0 | 1`.

⚠️ **Коллизия чипов — по пикселям, а не по времени.** Чип имеет минимальную ширину
под текст: звонок в 09:00 и задача в 09:40 по времени не пересекаются, а на дорожке —
лягут друг на друга. Поэтому для упаковки каждый интервал расширяется до номинала:

```ts
const CHIP_NOMINAL_MIN = 100; // ~ширина чипа в минутах оси при 7 колонках
const span = Math.max(item.endMin - item.startMin, CHIP_NOMINAL_MIN);
```

Больше двух рядов не заводить: третий пересекающийся чип в ряду 2 получает
сжатие до иконки+времени (title в `aria-label` и native tooltip). На живых данных
(≤4 события в день) это край, но он обязан быть обработан — не наложением.

Тест: три события подряд с шагом 30 минут → ряды 0,1,0; четыре плотных → сжатие.

## ЗАДАЧА 3: компонент `WeekLanes.tsx`

`src/components/calendar/WeekLanes.tsx`, пропсы — те же, что у `WeekGrid`
(`weekStart, tasks, meetings, onSlotClick, onBlockClick, onMeetingClick` +
дедлайны из разведки). `onReschedule` в v1 не принимается — уходит из ветки
`CalendarView` вместе с `DndContext`.

Структура (геометрия — из макета, все значения в rem/em/%):

- **Ось**: константы `START_HOUR`/`END_HOUR` из `grid-core` (07–22, не 08–20 макета —
  ось проекта едина). Позиция чипа: `left = (startMin - START_MIN) / (END_MIN - START_MIN) * 100%`.
- **Строка дня** = grid `9rem 1fr`: паспорт + дорожка. Мин-высота дорожки 3.4rem,
  при двух рядах 4.2rem. Выходные — фон `--surface2`. Сегодня — фон `--accent-l`
  + `inset 3px 0 0 var(--accent)`.
- **Паспорт дня**: `Пн 11` + счётчик справа (`--text-mute`, tabular-nums) +
  строка окна из `formatFreeWindow` (акцентная часть — `--accent`, вес 600).
  Задачи дня без времени: строка `+N без времени` в паспорте, `--text-mute`.
- **Чип** = `<button>`: иконка вида + `HH:MM` (вес 600, tabular-nums) + название.
  Радиус 999px, паддинг `0.25rem 0.6rem 0.25rem 0.45rem`, текст 0.6875rem.
  **Иконка и цветовая пара — только из `KIND_META`** (`lib/timeline/kind-meta.ts`).
  Третьей карты «вид → иконка» в проекте не появится: две уже сливали в одну.
  Тинты фона: звонок `--blue-l`/текст `--blue`, встреча `--purple-l`/`--purple`,
  задача `--surface` + `border --border2`, критичный приоритет — бордер и текст
  `--danger`, дедлайн сделки — `--danger-l`/`--danger` + иконка Flag.
  Название внутри чипа — `--text` (не цветом вида), max-width + ellipsis.
- **Дедлайны сделок** — чипы без времени, прижаты к левому краю дорожки, ряд 0.
- **Линия «сейчас»** — вертикаль через все дорожки: `2px solid var(--danger)`,
  метка `HH:MM` сверху (фон `--danger`, текст `#fff`), позиция от
  `mskMinutesOfDay`, рендер только если сегодня входит в неделю. Часовая
  вертикаль сетки — `--border` с opacity 0.6, подписи часов над дорожками.
- **Клик по пустому месту дорожки** — `onSlotClick(day, hourFromX)`: час из
  доли ширины, создание события сохраняется как было.
- Ховер чипа: `translateY(-1px)` + `--shadow-md`, `transition .15s var(--ease-out)`;
  `@media (prefers-reduced-motion: reduce)` — без движения.
- Легенда видов внизу — как в макете, из того же `KIND_META`.

A11y: чипы — `<button>` с `aria-label` вида «Звонок 10:10, Хороший вкус»;
`focus-visible` — кольцо `--accent` (в тёмных темах уже настроено глобально);
эмодзи нет, иконки Lucide.

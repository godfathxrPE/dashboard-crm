# Claude Code — S-CHAT-HUB-1f: визуальная идентичность мессенджера

**Эпик CHAT-HUB, фаза 1f — «дать жизни».** Сейчас чат выглядит как любая карточка
дашборда: та же поверхность, та же рамка. Задача — сделать раздел визуально СВОИМ,
оставаясь строго внутри токен-системы 7 тем. Концепт согласован с Олегом —
`_analysis/chat-visual-concept.html` (открой и смотри при вёрстке, там 6 приёмов).

**Миграций НЕТ, БД не трогается.** Ни одного нового запроса к Supabase — всё видимое
считается из уже загруженных данных.

**Ветка:** `feat/chat-hub-1f`. Функциональные заимствования из Telegram, требующие
схемы (ответы-цитаты, пины), — НЕ здесь, это CHAT-HUB-2 после наполнения данными.

## КЛЮЧЕВЫЕ РЕШЕНИЯ (принять как есть)

1. **Идентичность раздела делают обои, а не перекраска.** Паттерн из «чатовых» дудлов
   (пузыри, скрепка, смайл) — один SVG data-uri через **CSS mask**, цвет и прозрачность
   из токенов темы. Никаких растровых картинок и внешних запросов.
2. **Шесть новых токенов на тему**, рядом с существующими `chat-own`:
   `--chat-bg` (фон ленты), `--chat-pattern-ink` + `--chat-pattern-op` (обои; светлые темы
   ~0.05, тёмные glass ~0.035), `--chat-in-bg` + `--chat-in-border` (входящий пузырь),
   `--chat-chip` (полупрозрачная подложка день-чипа/реакций поверх обоев).
   Все значения — производные существующих токенов темы, не новые краски.
3. **Цвет имени автора во входящем пузыре** — из той же 8-цветной палитры
   `chat-avatars.ts`, hash по `author_id`. Один источник цвета для аватара человека и его
   имени (паттерн Telegram). Для light-тем брать тёмный конец пары (контраст).
4. **Опасити-правило visual-audit не нарушаем:** паттерн — чисто декоративный слой
   (`pointer-events:none`, без текста), низкая opacity легальна. Информативный текст
   по-прежнему только токенами.
5. **Разделитель «Новые сообщения»** считается от `last_read_at`, **снятого при открытии
   канала до того, как `useMarkRead` его сдвинет** — снапшот в ref/стейт при смене
   `conversationId`, единожды. Данные уже в кэше `useConversations` — нового запроса нет.
6. **Драфты композера — per-канал в Zustand (in-memory, без persist).** Переключился на
   другой канал и вернулся — текст на месте; перезагрузка страницы его теряет, это
   осознанный v1.
7. **Анимации уважают `prefers-reduced-motion`** — новые keyframes оборачивать в
   `@media (prefers-reduced-motion: no-preference)`.

## ЗАДАЧА 1 — Токены и обои (`globals.css`)

- Блок `/* ═══ CHAT-HUB 1f: чат-токены ═══ */` рядом с существующими `.chat-own`:
  шесть токенов × 7 тем (`t-aura`, `t-washi`, `t-fuji`, `t-frost`, `t-aurora`, `t-tidal`,
  `t-minimal`). Ориентиры: `--chat-bg` = `--bg` темы (лента «утоплена» относительно
  surface-панелей); `--chat-in-bg` = `--surface`; тёмные glass — solid-версии (как
  `[data-modal]`-оверрайды: сквозь полупрозрачный surface обои бы просвечивали дважды).
  `--chat-pattern-ink`: светлые — `--accent-text` темы, тёмные — светлый акцент.
- Класс `.chat-wallpaper::before` — mask-паттерн (SVG воспроизвести близко к концепту:
  пузырь, скрепка, смайл, три точки, стрелка; тайл ~8.75rem). `content:''`, `inset:0`,
  `pointer-events:none`.
- `t-minimal` — самая строгая тема (пузырь = чёрный `--text`): обои дать почти
  неразличимые (op ~0.03), идентичность там держат пузыри и композер.

## ЗАДАЧА 2 — Лента и пузыри (`MessageThread`)

- Скролл-область: `bg-[var(--chat-bg)]` + `.chat-wallpaper`; рамку `border-border/50`
  оставить.
- **Входящие** — пузырь `--chat-in-bg`/`--chat-in-border` (сейчас чужие сообщения без
  пузыря/на surface2 — проверь фактическое и приведи к токенам). Имя автора — цветом из
  решения 3, только на `groupStart` (как сейчас).
- **Аватар собеседника — у ПОСЛЕДНЕГО сообщения группы** (Telegram-паттерн, «кто закончил
  реплику»); сейчас, вероятно, у первого — перенеси выравнивание (`items-end` ряда).
- **Хвостик**: на `groupEnd` — маленький радиус нижнего угла со стороны автора
  (`rounded-br-[4px]` у своих уже есть — добавь зеркальный входящим).
- **День-чип — sticky**: `position:sticky; top:0.4rem` внутри скролл-области, подложка
  `--chat-chip` + `backdrop-filter: blur(6px)`. Проверь на тёмных glass-темах.
- Реакция-чипы — подложка `--chat-chip` (сейчас surface2 — на обоях будет грязно).
- Time-штамп в пузыре — как был (`--chat-time`).

## ЗАДАЧА 3 — «Новые сообщения» и кнопка «вниз»

- Разделитель: линия + текст «Новые сообщения» перед первым сообщением с
  `created_at > снапшот last_read_at` (решение 5). Не показывать, если непрочитанного нет
  или канал открыт впервые (`last_read_at` отсутствует → всё «новое», разделитель у
  самого верха бессмыслен — не рисуем).
- FAB: круглая кнопка над композером, появляется когда скролл дальше ~300px от низа
  (слушатель scroll с rAF-троттлом); бейдж — счётчик сообщений, пришедших пока
  проскроллен вверх (локальный счётчик, сброс по клику/доскроллу). Клик — плавный скролл
  вниз (`behavior: reduced-motion ? 'auto' : 'smooth'`).
- Автоскролл-логика при новом сообщении сейчас есть — не сломай: если юзер У НИЗА,
  скроллим как раньше; если вверху — НЕ дёргаем, только счётчик FAB.

## ЗАДАЧА 4 — Композер-капсула

- Вынести композер в капсулу: скруглённая поверхность `--surface` с рамкой, скрепка и
  эмодзи внутри, лёгкая тень. Лента прокручивается ПОД ним визуально (композер поверх
  нижней кромки скролл-области, как в концепте) — либо честный вариант без перекрытия,
  если поверх ломает высоты; решишь по месту, скриншот покажет.
- `<textarea>` авторастёт до ~6 строк (scrollHeight-приём), дальше внутренний скролл.
- Кнопка отправки: пустой драфт — приглушённая; непустой — заливка `--accent`
  (существующее правило `.bg-accent` тем возьмёт контрастный тон само) + лёгкий
  scale-переход.
- **Драфты**: `chatDraftByConversation: Record<string,string>` в `ui-store` (Zustand,
  БЕЗ persist-ключа — см. решение 6). При отправке — очистка.

## ЗАДАЧА 5 — Пустые состояния и микродвижение

- Пустой канал: по центру обоев — крупная иконка `MessagesSquare` в мягком круге
  `--chat-chip` + существующий `emptyText`. На обоях это уже не «дырка», а приглашение.
- `animate-appear` оставить; добавить короткий pop реакции при постановке
  (scale 0.6→1, ~150ms, spring-ease из токенов `--ease-spring`) — под
  `prefers-reduced-motion: no-preference`.
- Ховер-контролы сообщения (реакция/правка/удаление) — без изменений.

## EDGE CASES

- Обои не должны попасть в `ProjectChat`-вкладку АВТОМАТИЧЕСКИ — там та же
  `MessageThread`. Реши через проп `variant?: 'page' | 'card'` (хаб — page с обоями,
  вкладка — card как сейчас) — вкладка на карточке сделки визуально остаётся карточкой
  среди карточек.
- Печать/узкий экран: sticky-чип и FAB не перекрывают композер (проверь 375px).
- Разделитель «новые» не дублируется при realtime-инвалидации (снапшот не пересчитывать).
- Длинное сообщение без пробелов — `break-words` уже есть, не потеряй при переносе
  разметки.
- RTL не поддерживаем — не усложняй.

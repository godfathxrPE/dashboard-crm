становится прошлое.

## ЗАДАЧА 3 — washi: текущая «в норме» не чёрная плита

В `globals.css` рядом с `--profile-*` (после `:root`, порядок решает):
```css
:root    { --profile-now: var(--mark-today); }
.t-washi { --profile-now: color-mix(in srgb, var(--text) 78%, transparent); }
```
В `StageProfile.tsx` заливка текущей `ok` и нижняя часть `over`/`warn` — `var(--mark-today)` →
`var(--profile-now)`. Контур, узел, линия «сегодня» и шкала кокпита — **не трогать**
(`--mark-today` остаётся там). 78%, а не 55%: прошлый факт в washi — `--text` 55%, текущая
обязана остаться темнее прошлого.

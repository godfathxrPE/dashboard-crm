Что войдёт в S-NOTES-2 и что нет

ВходитЗоны «Закреплено» (суть сделки + до 3 заметок) → «Запланировано» → история по дням. Карточки касаний, строка стадии с комментарием, склейка изменений полей. Правка заметки на месте с панелью markdown, вставка HTML из буфера как markdown, рендер своим парсером без HTML. Закрепить / открепить, удалить с «Вернуть». «Изменить» у встречи и звонка открывает их окно правки. Плитка «Последнее событие» и карточка «Закреплено» в правой колонке уходят. Миграция 135: снятие моста trg_zz_notes_bridge.
Не входит — S-NOTES-3Вкладки композера (звонок, встреча, задача из ленты), поиск по ленте (RPC уже умеет p_search), та же лента у лида, компании, контакта и внедрения, «Задача из заметки».
Визуал истории (v2, 03.10)Слева — шпиль ленты: короткие сегменты между узлами, линия не касается кружков (v2.1). Узлы по типу касания: заметка — жёлтый, встреча — фиолетовый, звонок — синий, смена стадии — акцентный узел-флаг и подкрашенная карточка «было → стало». Системные строки — мелкие точки на шпиле. Дни — пилюли на шпиле. Иконка типа переехала из карточки в узел, в карточке тип — пилюлей (вариант Б). Боковых кантов нет нигде. Статус встречи и звонка — нейтральный текст с галочкой, а не зелёная пилюля: так цветов в рабочей зоне четыре типовых и красный для просрочки.
Чем платим«Суть сделки» и закреплённые заметки — два источника в одной зоне: поле без автора и истории, заметки с ними. Зато AI, автоматизации и гейт стадии продолжают работать с коротким полем без переделки. Цвет по типу — ещё три оттенка в ленте: держим их только в узле и подписи, фон карточек остаётся нейтральным, кроме заметок. Правка — markdown в поле, а не WYSIWYG: звёздочки видны, пока пишешь. Формат хранения тот же, WYSIWYG можно поставить позже без миграции.

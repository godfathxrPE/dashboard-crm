# Fix DEADLINES-1-AXIS — крупнее ОСЬ, а не строки задач

**Ветка:** `fix/deadlines-1-visual`, поверх `85c7a02`. **Не смержено, PR не открыт.**
Один файл `src/components/projects/DealDeadlineTrack.tsx`. Миграций нет, домен не трогаем.

## Зачем — и что было понято неверно

Владелец просил «маркеры событий развести, увеличив расстояние между ними». Это было
прочитано как «поднять высоту СТРОКИ ЗАДАЧИ» (18px → 26px). Прочтение неверное: расти
должен **график** — ось дней и её поле, — а строки задач остаются компактными. Строка
задачи это список, а не шкала; её рост делает виджет длиннее, но не делает его графиком.

Правка отменяет часть прежнего решения (дорожка 26px) и переносит прибавку туда, где она
и была нужна.

## Таблица размеров — только это и меняем

| Элемент | Сейчас (после 7ab3fc6) | Стало |
|---|---|---|
| высота строки задачи | `h-[1.625rem]` 26px | **`h-[1.125rem]` 18px** — откат к спеке W3 |
| подпись задачи | `text-[0.625rem]` 10px | **без изменений** — «текст уменьшить» в силе |

| кружок дня | `size-[1.125rem]` 18px | **`size-6` 24px** |
| высота ряда оси | `h-[1.375rem]` 22px | **`h-[2rem]` 32px** |
| колонка «сегодня» | `w-[2.125rem]` 34px | **`w-[2.75rem]` 44px** |

Колонка растёт вместе с кружком дня намеренно: она обязана оставаться шире его, иначе
кружок «08» вылезет за свою же подложку.

## Чего НЕ делать

- Не трогать `deadline-track.ts` и его тесты — правка чисто размерная.
- Не увеличивать точку маркера. Событие на шкале не обязано конкурировать с делением
  оси; при 24px кружке дня 12px точка читается нормально.
- Не возвращать подпись задачи к 11px — требование «текст задачи уменьшить» отдельное
  и остаётся в силе.
- Не трогать шесть пунктов из `fix-DEADLINES-1-VISUAL.md` (eyebrow, легенда сверху,
  базовая линия, подпись нормы у пунктира, состояние словом) — они приняты.

## Проверка соразмерности

После правки посмотреть глазами: кружок «сегодня» (24px + свечение) не должен вылезать
за колонку 44px, а базовая линия оси — оставаться прямой на всю ширину. При семи задачах
блок с дорожками 18px возвращается к прежней высоте — тот расчёт уже делался и держится.

# Claude Code Prompt — Fix: цена Claude Sonnet 5 + пуш

Гейт сверил `PRICE_BY_SLUG` с первоисточником
([Pricing — Claude Platform Docs](https://platform.claude.com/docs/en/about-claude/pricing)).
Все строки совпали дословно, кроме одной.

**Правка haiku подтверждена и оказалась важнее, чем выглядела:** Haiku 4.5 действительно
$1/$5, а прежние 0.8/4 — это прайс **Haiku 3.5**, снятой с поддержки модели. Проект считал
расход по цене модели, которой в проде нет.

**Ошибка — в `claude-sonnet-5`.** Обоснование «до 31.08 вводная $2/$10, вношу списочную
$3/$15, чтобы не устарело через 13 дней» опирается на повышение, которого **не будет**.
В документации стоит прямая нота: цена $2/$10, объявленная при запуске как вводная до
31 августа 2026, **стала стандартной**, а переход на $3/$15 с 1 сентября отменён.

Следствие: «фактический расход» завышен в полтора раза для всех sonnet-прогонов — то есть
для большинства пресетов. Ровно тот вид правдоподобного вранья, ради которого делался фикс.

## ЗАДАЧА 1 — таблица

`src/lib/constants/ai-presets.ts`

Строка ~208:

```ts
'claude-sonnet-5': { in: 3, out: 15 },
```
→
```ts
'claude-sonnet-5': { in: 2, out: 10 },
```

Блок комментария выше (строки ~199–201, про «вводную цену до 2026-08-31») заменить —
рассуждение было верным по форме и неверным по факту:

```
 * ⚠️ `claude-sonnet-5` — $2/$10, и это СТАНДАРТНАЯ цена, а не акция. Объявленная
 * при запуске как вводная до 2026-08-31, она стала списочной; запланированный
 * переход на $3/$15 с 1 сентября отменён (сверено с прайс-листом 2026-08-18).
 * Прежняя редакция этой таблицы держала $3/$15 «чтобы не устарело после акции» —
 * завышение в полтора раза на большинстве пресетов. Осторожность в сторону
 * завышения не безопаснее занижения: неверное число одинаково не годится там,
 * где его подписывают словом «факт».
```

Дату сверки в шапке таблицы (`сверено 2026-08-18`) не трогай — она верна, менялась
только одна строка внутри той же сверки.

## 4. AI-контур — что выяснено и что опровергнуто

**Опровергнуто (важно, не повторять):**

- «Из семи пресетов живёт один, AI повёрнут наружу» — **вывод неверен по источнику**.
  `ai_runs` не мог записать `ai-capture`, то есть весь AI по собственным данным был невидим.
  Правильная формулировка: *живёт AI, встроенный в поток ввода; не живёт требующий отдельного
  действия «запустить пресет»*.
- Ошибки `company_brief` 18.08 — **не** смена формата service-ключа Supabase и **не** отставший
  от OpenRouter пресет. Пробник: все функции отвечают `400` на битое тело ⇒ шлюз пропускает.
  В логах edge: `Claude API 400: "Your credit balance is too low"`. Банально баланс Anthropic.
- Роадмап держит риск «доступ к Claude API из РФ» открытым — фактически **provider seam есть**:
  адаптер `_shared/llm.ts`, провайдер и слаги моделей переключаются секретами. Capture идёт
  через OpenRouter (`anthropic/claude-haiku-4.5`). НЕ переехал только `company_brief` —
  он использует серверный web search Anthropic со своим протоколом.

**Первые данные из починенного лога (2 разбора, веб):**
вход ~11 000 токенов, выход ~140, длительность ~2 с, первый разбор вернул `unclear`.

## 6. Главный урок сессии — метод, а не факт

Пять раз за сессию механизм ломался **тишиной**, а не ошибкой:

1. `skill-deploy.sh` с захардкоженным списком — выходил с кодом 0 и печатал успех, не раскатав файл
2. RLS-политика `ai_runs_select` — строка легла бы в таблицу невидимой, а смок под `postgres` показал бы «есть»
3. Стаб типов через пересечение вместо `Omit` — `string & (string|null)` = `string`, не изменил бы ничего
4. Netlify — восемь красных крестов в каждом PR приучали не смотреть на красное
5. `source` не писался при отказе — «доля отказов по источнику» не ответилась бы

**И три раза правдоподобное объяснение оказалось выдуманным** при верном выводе: «ruleset
заблокирует мерж самого фикса», «игнор-блок нужен, иначе красный CI на файлах не из git»,
«AI повёрнут наружу». Последнее — моя собственная ошибка, построенная на слепом логе.

**Правило:** проверять причинную связь **отдельно** от результата, и применять это к своим
зачётам так же, как к чужим отчётам. Заявление «ruleset включён» было принято на слово —
при проверке правило оказалось одно из трёх.

# Claude Code Prompt — chore(skills): STE-lite формат отчёта в sprint-prompt-builder

Контекст: в скилл `sprint-prompt-builder` добавляется секция `## ОТЧЁТ` — константный
формат финального отчёта CC в стиле STE-lite (ASD-STE100, адаптация для русского).
Цель: гейт сверяет строки «Сделано» с диффом 1:1, без чтения свободного текста.
Меняется только `sprint-prompt-builder/SKILL.md`. Код приложения не трогать.

### 2.3 Скелет промпта — секция ОТЧЁТ после КОММИТ

Якорь — конец блока «Prompt Structure» (строки «## КОММИТ», «git add/commit…» и
закрывающий ``` скелета). Проверка уникальности:
`grep -n "git add/commit with descriptive message" sprint-prompt-builder/SKILL.md` → 1 строка.

old:
~~~~
## КОММИТ
git add/commit with descriptive message
```
~~~~
new:
~~~~
## КОММИТ
git add/commit with descriptive message

## ОТЧЁТ
Финальный ответ CC в чат — по формату ниже (блок копируется в спринт без изменений)
```

Секция ОТЧЁТ — **константа**, одинаковая во всех спринтах. Шаблоны из
`references/templates.md` заканчиваются на КОММИТ — ОТЧЁТ добавляется ко всем. Зачем:
отчёт CC читает гейт; свободный текст с оценками («всё работает отлично») нельзя
сверить с диффом, строка «`файл` — что изменено» сверяется механически. Стиль —
STE-lite: правила ASD-STE100 (контролируемый английский техдокументации), перенесённые
на русский без словаря.

```markdown
## ОТЧЁТ

Финальный ответ в чат — строго в этом формате. Стиль STE-lite:
- Предложение ≤ 20 слов. Одно предложение — один факт или одно действие.
- Активный залог, прошедшее время: «добавил индекс», не «индекс был добавлен».
- Один термин = одно значение. Сущности называй как в коде: имя файла, таблицы, функции.
- Без оценок: «отлично», «полностью», «успешно», «готово к проду» — запрещены.
  Вместо оценки — артефакт: число, вывод команды, exit code.
- Не больше 3 существительных подряд. Без цепочек «осуществление проведения проверки».
- Списки вертикальные, вложенность ≤ 1 уровня.

Сделано
- `путь/к/файлу` — что изменено. Одна строка на файл или на одно изменение.

Проверки
- `команда` → результат (0 ошибок tsc · 42 теста passed · build exit 0).

Не сделано
- Что пропущено и почему. Пусто → «—».

Отклонения от спринта
- Где сделал иначе, чем в файле спринта, и почему. Пусто → «—».

Вопросы и риски
- Не больше 3 пунктов. Пусто → «—».
```
~~~~

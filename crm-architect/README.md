# crm-architect — память проекта

Скилл, из которого собирается каждый спринт и по которому проверяет гейт: схема,
структура файлов, дизайн-система, конвенции, накопленные грабли. Читают его двое —
Claude Code (локальная копия скилла) и Cowork-сессии (копия в аккаунте Claude.ai).

**Правь здесь, а не в `~/.claude/skills/crm-architect/` и не в аккаунте.** Обе те копии
— производные: правка в них не переживёт следующую раскатку и не попадёт в ревью.
Обратной синхронизации нет намеренно (три разошедшиеся копии 2026-08-05 стоили гейту
ложного вывода по версии месячной давности).

```bash
./scripts/skill-deploy.sh   # раскатать: репо → ~/.claude/skills/ + пакет crm-architect.skill
./scripts/skill-verify.sh   # сверить репо с локальной копией (0 — идентичны, 1 — дифф)
```

Пакет `crm-architect.skill` создаётся в корне репозитория (в git не попадает) и
**загружается руками**: Claude.ai → Customize → Skills. Без этого шага Cowork и гейт
продолжают читать прежнюю версию памяти — скриптом это не проверить.

## Файлы

- `SKILL.md` — точка входа: идентичность проекта, форматы ответа, типы задач, чеклист качества спринт-промпта.
- `references/schema.md` — указатель по БД: куда идти за истиной + конвенции RLS/грантов (сами таблицы — в `docs/schema.md` репозитория).
- `references/architecture.md` — дерево файлов, паттерны компонентов, хуки, состояние, роутинг.
- `references/theme-system.md` — CSS-переменные, 7 тем, слои и z-index.
- `references/learnings.md` — грабли и проверенные решения из 40+ спринтов; читать перед любым спринт-промптом.

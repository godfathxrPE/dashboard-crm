## 0. Вердикт

Карточка сделки — **единственная детальная страница проекта без горизонтального
ограничителя и без разделения «работа / контекст»**. `CompanyDetail` этот вопрос уже решила
(`grid lg:grid-cols-[minmax(0,1fr)_320px]`, строка 250) — карточка сделки паттерн не
унаследовала и осталась вертикальным стеком full-bleed-полос. Свёрнутый сайдбар не создаёт
проблему, он её обнажает: при `ml-14` ширина контента = `100vw − 56 − 48`, и каждый виджет
растягивается на всю эту ширину независимо от того, сколько в нём данных.

Дефект **не в виджетах, а в двух системных решениях**: (1) нет `max-width` у полотна,
(2) нет правой колонки контекста. Из-за (2) страница платит вертикалью за справочные данные:
до вкладок и ленты — **≈700 CSS px хрома** [ESTIMATED по скриншоту], лента открывается под
сгибом на любом ноутбуке.

Счёт: **1 Blocker · 3 High · 4 Medium · 3 Polish.**

**Почему 320, а не 360/380.** `CompanyDetail` уже стоит на 320, `DealSignals` уже имеет
`md:w-80` (= 320). Второе значение для той же роли — начало дрейфа; system-ответ —
переиспользовать существующее.

**Почему 1440.** Левая колонка получает ≈1040 px — хватает Ганту и доске задач внутри
вкладок; текст ленты остаётся в пределах меры. 1280 сделает Гант теснее, 1600 вернёт
растянутость на 4K. Значение — токен, менять в одном месте.

**Вертикальный бюджет.** До вкладок сейчас ≈700 px, после ≈390 px [ESTIMATED]:
back+шапка 90 · кокпит 150 (guidance свёрнута, «Пройдено» снято) · «Следующий шаг» 110 ·
вкладки 34. Лента открывается на первом экране 1080p, видимых событий примерно вдвое больше.

## 4. Что ломается и как это обойти

| Риск | Механика | Решение |
|---|---|---|
| `ActivityDrawer` | `layout.tsx` даёт `marginRight: 280` при открытом drawer. При cap 1440 + рельса 320 + drawer 280 левая колонка на 1440-экране ≈ 700 px | `min-w-0` на обеих колонках (у `CompanyDetail` уже так) + брейкпоинт: рельса схлопывается ниже `lg` (1024). Cap применяется к доступной ширине, не к вьюпорту — `mx-auto` внутри уже сдвинутого контейнера |
| Порядок на узком | Ниже `lg` рельса уезжает вниз, и «Здоровье» окажется под лентой | Явные `order-*`: шаг → сведения → здоровье → вкладки. На мобильном контекст обязан быть **над** лентой |
| Якоря сигналов | `scrollToSignalAnchor` ведёт на `#deal-next-step`, `#deal-info-grid`, `#deal-stakeholders`, `#deal-activity` | Все четыре id обязаны переехать вместе с блоками. `#deal-info-grid` меняет смысл (грид → property-list) — id сохранить, `data-stats-grid` проверить: на него может смотреть что-то ещё |
| `compact`-режим панели | Peek 440 px использует `DealFocusPanel compact` | Расщепление панели не должно сломать peek: `compact` собирает шаг + здоровье в одну колонку, как сейчас. Логичный шаг — `DealFocusPanel` оставить **только** для peek, а на полной карточке использовать новые `DealNextStepCard` + рельсу |
| Темы | 7 тем; `.content-shell` и property-list не должны нести цвет | Только layout-свойства; разделители — `border-border`, никаких новых цветовых токенов |
| Delivery / internal | Та же страница через `/projects/[id]` | Рельса собирается из тех же слотов, но «Здоровье сделки» → `DeliveryHealthDot`, «Бюджет» → «Родительская сделка». Проверять обе ветки, иначе `isDelivery` разъедется |

## 5. Порядок захода

**Спринт A — «Полотно» (≈0.4, без схемы, обратимо).**
L-01 токен + `.content-shell` на детальных страницах · L-06 снять «Пройдено %» ·
L-05 guidance сворачивается · L-09 «Создан» из шапки. Даёт половину эффекта за день
и проверяется скриншотом до/после в minimal.

**Спринт B — «Две колонки» (≈0.8, рефакторинг).**
L-02 сетка · L-03 расщепление фокус-панели · L-04 property-list · L-07 стейкхолдеры в
рельсу · L-11 вынос компонентов. Смоки: свёрнутый/развёрнутый сайдбар × drawer открыт/закрыт
× 1280/1440/1920 × minimal/aura, плюс delivery-ветка и peek-панель.

**Спринт C — «Материалы во вкладку» (≈0.3).**
L-08 + добивка F-04 (компактные пустые состояния файлов и видео) + L-10.

Порядок не переставлять: B поверх непричёсанного полотна даст двухколонник, который на 4K
всё ещё разъезжается; C до B добавит седьмую вкладку в стек, который через неделю
переедет.
